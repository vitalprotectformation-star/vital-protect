Correctif cards marketplace

Ce correctif retire l'image en <img> placée au-dessus de la card.
La card complète devient maintenant le background direct de la carte.
Le texte est injecté dans un bloc HTML positionné en premier plan avec z-index forcé.

Images utilisées :
- vp-card-prevenir-module.webp : visuel femme / mise à distance
- vp-card-self-pro.webp : visuel accueil / situation tendue professionnelle
- vp-card-formateur-reseau.webp : visuel groupe de formateurs

Fichiers à remplacer :
- stage.html
- devenir-formateur.html
- vp-card-prevenir-module.webp
- vp-card-self-pro.webp
- vp-card-formateur-reseau.webp

Après déploiement Vercel : faire Ctrl + F5.
