Correctif cards marketplace Vital Protect

Contenu :
- stage.html : cards en recto/verso au clic.
- admin.html + api/admin-tools.js : conservation de la gestion des descriptions de modules.
- vp-card-prevenir-module.webp : visuel Prévenir, éviter, réagir.
- vp-card-self-pro.webp : visuel milieu professionnel.
- vp-card-formateur-reseau.webp : visuel formation de formateur / réseau.

Fonctionnement :
- Premier clic sur une card : retourne la card et affiche le descriptif du module + informations secondaires.
- Deuxième clic sur une card stage : sélectionne le stage / active la réservation.
- Deuxième clic sur une card formateur : ouvre la page devenir-formateur avec la session.

Les descriptions affichées au verso viennent en priorité de training_modules.long_description, puis short_description, puis une description par défaut.
